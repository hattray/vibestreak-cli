# Security

The CLI reads your AI tools' local history and your git log, and uploads daily
counts only. If you find a way it sends more than that (prompts, code, file
paths, repository names, commit messages or email addresses), or any other
security problem in the CLI or the service, please report it privately:

- GitHub: **Security → Report a vulnerability** on this repository, or
- email support@kingsbridge-consultancy.com

Please don't open a public issue for it. We'll reply within a few days.
